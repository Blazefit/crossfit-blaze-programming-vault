# Blaze Cycles — personal training-cycle library

Self-contained single-file app for Jason's personal, rotate-able training cycles
(separate from the gym class programming in `../cycles/`).

- `blaze-app.html` — the app. Each program is one entry in the `CYCLES` registry;
  the bottom-nav ☰ button / header chip open a cycle switcher.
  Live at: https://crossfitblaze.com/openclaw/blaze-ppl/
- `index.json` — catalog of cycles.
- `archive/` — pristine snapshots of each cycle version.

Cycles: **Arm & Bicep** (8-wk heavy linear, active) · **Shoulder & Delt** (5-wk rear-delt blitz, draft v1).
